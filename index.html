ZUJ Events Hub

University event management graduation project built with ASP.NET Core MVC, SQL Server, Entity Framework Core, Admin/Student roles, event booking, capacity control, and waiting list logic.

View Repository

Project Overview

ZUJ Events Hub is a web application designed to organize university events. Administrators can manage events and monitor bookings, while students can browse events, book available seats, join a waiting list when capacity is full, and cancel bookings.

Main Features

Admin Dashboard

Manage events, view statistics, track active bookings, and review registered students.

Student Booking

Students can search events, book seats, cancel bookings, and view their reservations.

Capacity Control

The system prevents overbooking and moves students to a waiting list when events are full.

Role-Based Access

Admin and Student areas are protected using session-based role validation.

Technology Stack

ASP.NET Core MVC .NET 8 C# Entity Framework Core SQL Server LocalDB Razor Views Bootstrap AdminLTE FullCalendar BCrypt

Academic Value

The project demonstrates MVC architecture, database relationships, CRUD operations, role-based access control, password hashing, EF Core migrations, and business-rule handling for event capacity and waiting lists.
